# seenbyangad.com

Everything you'll want to change is in `index.html`. Search for ✏️ to find each spot.

- **Where you are**: change "Currently in Budapest".
- **Add a photo**: upload it to `photos/`, then add its file name to the PHOTOS list near the bottom of `index.html`. Add ` big` after the name to make it large.
- **Notes**: each `<div class="frame">` block is one photo plus a title and text. Copy one to add another.

Photo tips: landscape, at least 1500px wide, under ~1MB each.
